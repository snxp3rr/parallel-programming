# Параллельное программирование

Учебный репозиторий по дисциплине «Параллельное программирование».

В рамках репозитория исследуется распараллеливание вычислительной задачи — перемножения двух квадратных матриц.

Используемые языки:

- C++23
- Python 3
- CMake / Ninja
- NumPy для автоматизированной верификации

## Цель репозитория

Получить базовые данные о производительности последовательного алгоритма умножения квадратных матриц, а затем использовать их как точку отсчёта для сравнения с параллельными реализациями:

- OpenMP;
- MPI;
- CUDA.

## Используемая задача

В качестве экспериментальной задачи выбрана операция перемножения двух квадратных матриц:

\[
C = A \times B
\]

где:

- \(A\) — матрица размера \(N \times N\);
- \(B\) — матрица размера \(N \times N\);
- \(C\) — результирующая матрица размера \(N \times N\).

Классический алгоритм умножения матриц имеет асимптотическую сложность:

\[
O(N^3)
\]

Количество арифметических операций приблизительно равно:

\[
2N^3 - N^2
\]

то есть:

- \(N^3\) умножений;
- \(N^2(N - 1)\) сложений.

## Быстрая сборка

Из корня репозитория выполни:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

После сборки исполняемые файлы будут находиться здесь:

```text
build/extra/MatrixGenerator
build/lab_1/lab1
```

---

## Быстрый запуск

Сгенерировать матрицы размера `20x20`:

```bash
./build/extra/MatrixGenerator 20
```

Перемножить матрицы:

```bash
./build/lab_1/lab1 20
```

Проверить результат через Python/NumPy:

```bash
python3 scripts/verify_numpy.py 20
```

---

## Запуск всех размеров из лабораторной работы

Используются размеры:

```text
20, 100, 250, 500, 1000, 1500, 2000
```

Команда:

```bash
for side in 20 100 250 500 1000 1500 2000; do
    echo "=== side = $side ==="

    ./build/extra/MatrixGenerator "$side" 12345
    ./build/lab_1/lab1 "$side"
    python3 scripts/verify_numpy.py "$side"
done
```

Здесь `12345` — fixed seed для воспроизводимости. Если seed не указывать, матрицы будут генерироваться случайно каждый раз.

## Форматы файлов

Входные матрицы хранятся в формате:

```text
N
a00 a01 a02 ...
a10 a11 a12 ...
...
```

где `N` — количество элементов в строке, то есть сторона квадратной матрицы.

Пример имён файлов:

```text
extra/matrices/A_20.txt
extra/matrices/B_20.txt
```

Результирующий файл содержит сначала отчёт, затем разделитель, затем саму матрицу:

```text
N=20
time_seconds=...
time_ms=...
integer_operations=...
memory_bytes=...
gops=...
a_file=extra/matrices/A_20.txt
b_file=extra/matrices/B_20.txt
output_file=extra/res/C_20.txt
--- MATRIX ---
20
...
```

Пример имени результата:

```text
extra/res/C_20.txt
```

## Примечания

1. Проект использует экспериментальную возможность CMake — `import std`.
   Поэтому при конфигурации может выводиться предупреждение вида:

   ```text
   CMake's support for `import std;` in C++23 and newer is experimental.
   ```

   Это нормально, если сборка проходит успешно.

2. Для замеров времени обязательно использовать сборку `Release`:

   ```bash
   -DCMAKE_BUILD_TYPE=Release
   ```

   В `Debug` программа будет работать значительно медленнее, и результаты будут нерепрезентативными.

3. Перед повторной конфигурацией CMake иногда полезно удалять папку сборки:

   ```bash
   rm -rf build
   ```

4. Все пути в примерах указаны относительно корня репозитория `PP`.
